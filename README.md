# 👁️ 20·20·20 — Eye Break Timer

تطبيق ويب بسيط كيطبق القاعدة الطبية **20-20-20**: كل 20 دقيقة قدام الشاشة، شوف شي حاجة بعيدة 6 ميترو (20 قدم) لمدة 20 ثانية.

**🔗 جربو هنا:** https://medo01012001.github.io/eye-break-20-20-20/

- عداد 20 دقيقة مع رنين وإشعار فالحاسوب
- عداد راحة 20 ثانية كيعاود يبدا بوحدو
- إحصائيات اليوم، ثيم غامق/فاتح، إعدادات قابلة للتعديل
